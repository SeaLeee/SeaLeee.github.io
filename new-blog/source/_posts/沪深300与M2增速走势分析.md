本文通过对比分析**沪深300指数**与**M1-M2同比增速差值**的历史走势，探索货币流动性结构对股市的影响机制，并基于数据模型提供每日投资建议。

### 🎯 核心指标说明

- **沪深300指数**: 反映A股市场整体表现的重要指标

- **M1-M2增速差**: 反映资金活跃度，正值表示资金更活跃，负值表示资金沉淀
- **相关性分析**: 沪深300与M1-M2差值的历史关联度

    signal_score = 0
    
    # M2增速信号
    if m2_growth > 8.0:
        signal_score += 2  # 强烈利好
    elif m2_growth > 7.5:
        signal_score += 1  # 适度利好
    elif m2_growth < 6.5:
        signal_score -= 2  # 利空
    
    # 相关性背离信号
    if correlation < 0.4:
        signal_score += 1  # 可能反转
    
    # 技术面信号
    ma30 = calculate_ma(hs300_price, 30)
    if hs300_price > ma30 * 1.02:
        signal_score += 1
    elif hs300_price < ma30 * 0.98:
        signal_score -= 1
