4.5 配置 GitHub Pages

  2. 进入 Settings > Pages
  3. 在 Source 下选择：

    • Folder: / (root)
  4. 点击 Save 保存

七、常见问题

7.1 命令找不到

如果提示 hexo 或 npm 命令找不到，检查环境变量配置。

7.2 部署失败

  • 确认 GitHub 仓库地址正确
  • 确认 Git 已正确配置用户信息
  • 检查网络连接

7.3 主题样式不显示

运行 hexo clean 清理缓存后重新生成。
